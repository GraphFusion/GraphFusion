## From a pattern to a result

```gql test
MATCH (person:Person {name: 'Alice'})-[:Knows]->(friend)-[:Knows]->(next)
RETURN next.name AS friend_of_friend;
```

GraphFusion turns graph patterns into DataFusion plans. Scans, joins, recursive paths and aggregates run in the same query engine; results come back as Arrow batches.

<CardGrid>
  <Card title="GQL for connected data" icon="puzzle">Match relationships, explore paths, aggregate results and update a property graph with one language.</Card>
  <Card title="Embedded in your application" icon="setting">Use the Rust API or the CLI. Start in memory, then open a local database directory when you need persistence.</Card>
  <Card title="Arrow in memory, Parquet on disk" icon="document">Import columnar graph tables and consume Arrow results. Catalog and graph changes commit together.</Card>
  <Card title="An explicit support boundary" icon="list-format">The runtime implements a growing subset of GQL. Every reference page distinguishes executable features from syntax-only support.</Card>
